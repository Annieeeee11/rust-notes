# Talking about Import and Exports

## 1) Library

- you can simple use the keyword "use" to use any library

---

## 2) Import

- you can use mod to define/load a module and after that you can use keyword "use" to use the functions from it
- in rust we use " :: " which is a path seperator to seperator things
  in simple words it let you access things that are defined inside modules or namespaces.

---

## 3) Export

- you can make functions and others public and export it by using the keyword "pub"
